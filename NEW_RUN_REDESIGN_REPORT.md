# New Run Redesign Report

The initial form now asks only for title, research question, research goal, current bottleneck, and requested outputs.

Experimental constraints, success/failure criteria, non-goals, notes, run mode, visibility, and language are under an Advanced fields disclosure.

The right column renders a natural-language Research Brief. Raw Markdown markers and internal enum names are never shown in the visual preview. JSON, Markdown, and launch-prompt actions remain available in a sticky action row and operate locally without server submission.
