# Literature Information Architecture

Literature is a primary run view, parallel to Summary, Ideas, Knowledge Base, and Run Specification.

## Route hierarchy

- `/runs/<run>/literature/`: key papers, scope, and complete source list.
- `/runs/<run>/literature/<source>/`: complete citation, evidence role, support boundary, access level, and related research.
- Summary: three to five key papers plus scope.
- Knowledge: Read, Key papers, and References views.
- Idea detail: related literature before proposed comparison and detailed evaluation.
- Report: numbered citation preview with deep links.

Source records expose scientific reading context, not runtime hashes, claim IDs, receipts, or private notes. Empty synthetic fixtures state that individual records are unavailable rather than inventing them.
