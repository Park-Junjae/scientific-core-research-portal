# Target-context gate before transfer

## Question

Does the receiving biological context contain the state required by the transferred mechanism, and can that state be distinguished from a generic association?

## Logic

The transfer proceeds only if three links survive review: the context exposes the relevant target state, the intervention engages that state, and the proposed readout distinguishes target engagement from broad stress or selection.

## Weakest assumption

The synthetic case does not establish that the source-system context is reproduced in the receiving model. Source-system precedent therefore remains analogical.

## Decisive pattern

A context-matched effect should track the prespecified target state and disappear in the state-negative control without a parallel global burden signal.

## Review decision

Refine the context assay and controls before testing. No candidate-level conclusion is made.
