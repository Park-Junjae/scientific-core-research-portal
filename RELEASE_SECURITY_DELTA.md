# Release Security Delta

The sanitized release adds only generic controls needed to prove public-history safety:

- public release-security and build documentation;
- a deterministic cross-platform Python selector and dependency preflight;
- a reachable Git-object auditor driven by external markers;
- a safe-product and release-delta equivalence auditor;
- synthetic regression tests for private-path rejection, generic visibility-enum acceptance, and Python selection;
- build-script routing through the Python selector.

The delta changes no scientific content, public research claim, candidate, source relationship, or New Run interaction.
