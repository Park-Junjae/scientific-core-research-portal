# Custom Domain Future Plan

No custom domain is configured in Phase 1. After GitHub Pages is approved and stable:

1. Choose a laboratory-owned domain and confirm data-governance ownership.
2. Add the verified domain in repository Pages settings.
3. Add a reviewed `public/CNAME` only after DNS approval.
4. Update canonical metadata and verify HTTPS enforcement.
5. Repeat deep-link, PDF, accessibility, privacy, and cache-invalidation checks.

The project-site base path remains the supported default until this process is complete.
