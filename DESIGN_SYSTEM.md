# Design System

> **Superseded by [`DESIGN.md`](DESIGN.md).** This document describes the
> pre-refresh visual language and is kept for historical context only. Where the
> two disagree, `DESIGN.md` is normative: it holds the machine-readable tokens
> and the prose explaining the intent behind them.

## Character

Quiet, precise, work-focused. The structure follows the density and navigation pattern of the provided Co-Scientist reference while using original Scientific Core branding.

## Tokens

- Canvas `#f7f8f8`; surfaces white; sidebar `#f1f3f2`.
- Ink `#14201d`; secondary ink `#52605c`.
- Scientific green `#0b6b50`; focus `#087f5f`.
- Status colors: green done, blue running, amber review, red failed, purple-grey blocked.
- Border radius at or below 7 px. Shadows limited to PDF pages and subtle search elevation.

## Typography

System UI stack with Noto Sans KR fallback. Report prose uses Georgia with Noto Serif KR fallback. Type does not scale with viewport width and letter spacing is zero.

## Interaction

Familiar Lucide icons, visible labels for commands, tooltips through native titles for icon controls, 44 px primary touch targets, strong focus rings, semantic tables/headings, reduced-motion support.

## Layout

254 px desktop sidebar; content up to 1260 px; mobile shell below 760 px. Sections are unframed reading bands. Cards are used only for repeated runs or framed tools; no nested cards or decorative gradients.
