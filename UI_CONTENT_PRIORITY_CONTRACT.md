# UI Content Priority Contract

Reader-facing pages must prioritize scientific question, summary, ideas, evidence, comparison, expected result, complete reports, and reviewed literature.

The following are secondary by contract: scores, reviewer disagreement, weakest edge, stop conditions, source IDs, claim ledgers, terminal state, provider usage, receipts, and build information.

PDF count is never a scientific metric. Status is a colored dot plus text. Tags are plain inline text. Ordinary paragraphs and page sections are not cards. A dedicated report link may be shown only when a manifest report ID exists.

The Runs list has one literature metric: `literature_stats.analyzed_unique_total`. Its heading is `분석 문헌` in Korean and `Literature analyzed` in English. It is not replaced by cited-source, report-reference, load-bearing, discovered-record, or PDF counts. Unknown remains visibly unknown as `—`. The detailed Literature page, rather than the Runs list, owns the complete discovery, screening, review, deep-reading, evidence, citation, and report-reference funnel.
